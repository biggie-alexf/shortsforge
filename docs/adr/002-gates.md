# ADR-002: Гейты контроля на каждом шаге, всегда
Дата: 2026-09-01 · Статус: принято

## Контекст
Варианты: полный автомат до видео / апрув сценария + правки финала / контроль на каждом шаге. Одновременно выбран ритм «несколько батчей в день» — это 20–30 ручных решений в день на команду.

## Решение
Четыре обязательных гейта на каждое видео: G1 сценарий+раскадровка → G2 выбор клипов → G3 черновая сборка → G4 мастер. Автопропуска гейтов в MVP нет.

## Последствия
- Человек — осознанное узкое место; качество приоритетнее потока.
- Каждый гейт = экран во фронте + чат-правки на этом шаге.
- Пайплайн обязан уметь перезапускать любой шаг поштучно, не трогая остальные.
- Если поток захлебнётся — вернёмся к настраиваемым гейтам (зафиксировать как ADR-002b, поле auto_approve уже заложить в модель, выключенным).
