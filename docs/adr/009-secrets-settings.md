# ADR-009: Секреты — в БД через меню настроек
Дата: 2026-09-01 · Статус: принято

## Решение
Ключи провайдеров (Anthropic, ElevenLabs, прокси для yt-dlp и будущие) хранятся в таблице settings, шифруются симметрично (Fernet) ключом APP_SECRET из .env сервера. Редактируются на экране «Настройки»; значения в UI маскируются (показ последних 4 символов). Смена ключа применяется без рестарта (провайдеры читают settings на каждый запуск задачи).

## Последствия
- .env содержит только APP_SECRET, DATABASE_URL, REDIS_URL — никаких API-ключей.
- Экран настроек также хранит: голос ElevenLabs (voice_id), модель Anthropic, лимиты.
