# ADR-008: Скоуп и порядок сборки
Дата: 2026-09-01 · Статус: принято

## Решение
- Публикация на YouTube — вне скоупа MVP: сервис отдаёт mp4 + заголовок/описание/хэштеги, заливка руками. Кнопка «Опубликовать» — этап 2.
- Канал пока один: пресет канала (голос, ASS-шаблон, вотермарк, формат по умолчанию) живёт в конфиге; сущность ChannelPreset в модели заложена, UI управления — позже.
- Строим сразу сервисом (фронт + бэк вместе), а не CLI-first: команда работает через UI с первого запуска.
- Превью кандидатов на G2 — вертикальные mp4-сниппеты 3–5 с (2–3 на блок), клик = выбор.
- Имя сервиса: ShortForge.
