# ADR-005: Чат-правки — агент с инструментами над пайплайном
Дата: 2026-09-01 · Статус: принято

## Контекст
Требование: правки на каждом гейте естественным языком, включая высокоуровневые («сделай энергичнее», «добавь мемов/смешных звуков», «сделай короче»), плюс точечные (текст блока, замена клипа, голос, сабы).

## Решение
Чат — это Claude-агент (Anthropic API, tool use) с типизированными инструментами пайплайна: edit_script(block?), regenerate_block, replace_clip(block, candidate|query), regen_voice(params), restyle_subs(patch), retime(target_len), add_sfx(spec), set_music(mood), rerender(step). Высокоуровневая правка = агент сам раскладывает её в последовательность вызовов и показывает план перед выполнением.

## Последствия
- Каждый инструмент = идемпотентная операция воркера с записью в историю версий видео.
- У видео есть версии (v1, v2, …) и diff «что изменилось» в ленте чата.
- Контекст агента: паспорт видео (сценарий, блоки, клипы, стили) + библия форматов как системный промпт.
