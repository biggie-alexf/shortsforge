# ADR-004: Инфраструктура и бюджет
Дата: 2026-09-01 · Статус: принято

## Контекст
Ничего не куплено. Бюджет $100–200/мес. Ритм — несколько батчей (3 видео) в день.

## Решение
Один выделенный CPU-сервер (8 vCPU / 16–32 GB RAM / 300+ GB NVMe, класс Hetzner AX/CCX, ~$40–60), без GPU. Тяжёлые модели — через API; ASR — faster-whisper на CPU. Docker Compose, один хост.

## Бюджет-рамка (месяц)
- Сервер: $40–60
- Anthropic API (сценарии + чат-агент): $30–60
- ElevenLabs Creator/Pro: $22–99 (по фактическому расходу минут)
- Домен + резидентный прокси для yt-dlp (риск блокировок YouTube с ДЦ-IP): $10–30
Итого: укладываемся в $100–200.
