# ADR-003: Пользователи и авторизация
Дата: 2026-09-01 · Статус: принято

## Решение
3–6 пользователей (владелец + команда). Логин/пароль (bcrypt), сессионные куки, без ролей — все видят и могут всё. Регистрации нет: пользователей создаёт владелец через CLI/админ-страницу.

## Последствия
- Никакого OAuth/SSO в MVP.
- Audit-поле: кто апрувнул гейт и кто дал правку (для разбора качества позже).
