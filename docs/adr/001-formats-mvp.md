# ADR-001: Форматы MVP — A и B
Дата: 2026-09-01 · Статус: принято

## Контекст
Библия описывает 3 формата: A «секрет/разбор», B «мемный монолог», C «скетч на два голоса». У них разная сложность автоматизации (C требует кооп-геймплея и посадки реплик на действие).

## Решение
MVP поддерживает форматы A и B. Формат C — после обкатки конвейера.

## Последствия
- Пайплайн проектируется с полем format у заказа сразу (enum: A, B, C-reserved).
- B требует нейтрального обби-геймплея — hunter умеет искать «neutral pool» запросами, но качает под заказ (ADR-006).
