# ADR-011: Провайдеры с mock-режимом
Дата: 2026-09-01 · Статус: принято

## Решение
Каждый внешний слой — за интерфейсом с двумя реализациями: real и mock.
- LLM (сценарист, чат-агент): real=Anthropic API; mock=детерминированные шаблонные сценарии.
- TTS: real=ElevenLabs; mock=espeak-ng/тишина с ровным темпом + синтетические word-тайминги.
- Поиск доноров: real=yt-dlp поиск; mock=каталог заранее сгенерированных синтетических летсплеев (ffmpeg-генератор: движущиеся фигуры + шум).
- Скачивание: real=yt-dlp (+прокси из настроек); mock=копирование из каталога фикстур.
Режим выбирается per-provider: если ключ не задан в настройках — провайдер работает в mock и это видно в UI бейджем «MOCK».

## Последствия
Весь флоу тестируется концом-в-конец без ключей и без доступа к YouTube; включение реальных провайдеров — только ввод ключей в настройках.
