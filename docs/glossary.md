# ShortForge — глоссарий (ubiquitous language)

| Термин (RU) | Entity | Определение |
|---|---|---|
| Батч | Batch | Один запуск: список из N (обычно 3) заявок на видео. Привязан к каналу-пресету. |
| Заявка / видео-задача | VideoJob | Единица производства: игра + краткая идея + формат (A/B) → одно видео. Проходит статусы и 4 гейта. |
| Формат | Format | A «секрет/разбор», B «мемный монолог», C «скетч» (зарезервирован). |
| Сценарий | Script | Текст озвучки EN + метаданные (заголовок, хэштеги). Версионируется. |
| Блок | Block | Единица раскадровки: 3–8 с, текст + описание кадра + ключевые слова поиска. Сценарий = 5–9 блоков. |
| Донор | Donor | Найденный на YouTube летсплей-источник. Храним video_id, канал, окно таймкодов, транскрипт. |
| Кандидат | ClipCandidate | Вертикализованный сниппет 3–5 с под конкретный блок (2–3 на блок). |
| Клип | Cut | Выбранный кандидат, вошедший в сборку блока. |
| Озвучка | VoiceTrack | WAV от TTS + пословные тайминги (words.json). Диктует хронометраж. |
| Черновая сборка | RoughCut | Склейка клипов + озвучка + автосабы, без SFX/графики/цветокора. Смотрится на G3. |
| Мастер | Master | Финальный mp4 1080×1920 + метаданные. Версионируется (v1, v2…). |
| Гейт | Gate | Точка ручного апрува: G1 сценарий, G2 клипы, G3 черновая сборка, G4 мастер. |
| Правка | Correction | Сообщение в чате видео → план инструментов агента → новая версия артефакта. |
| Чат-агент | Agent | Claude с инструментами пайплайна, ведёт чат каждого видео. |
| Пресет канала | ChannelPreset | Голос, стиль сабов, вотермарк, дефолтный формат. Пока один, из конфига. |
| Охотник | Hunter | Воркер поиска и скачивания доноров под блоки. |
| Резчик | Cutter | Воркер вертикализации и нарезки кандидатов. |
| Сборщик | Mixer | Воркер финальной сборки ffmpeg (сабы, SFX, музыка, графика). |
| NEEDS_FOOTAGE | — | Статус блока, под который не нашлось кадров; решается в чате на G2. |
